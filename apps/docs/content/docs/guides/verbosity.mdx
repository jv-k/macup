# Verbosity

macup has three output modes:

- default: install and upgrade flows stream their subprocess output (download
  progress, `Password:` prompts, success messages) as lines in the same gutter
  as the rest of the UI, so it reads as one transcript. Queries (list, outdated,
  health) show an inline spinner while they run. `Error:` and `Warning:` lines
  from internal queries surface as one-line notices.
- `--verbose` / `-V`: the seam kept for future extra detail beyond the default
  gutter stream.
- `--debug` / `-D`: a full raw trace of every shell call routed to stderr,
  with timing, so you see exactly what each underlying command printed.

Activity feedback is a single append-only path, so it renders identically on
every terminal, under a pipe, and in CI. There is no capability probe or escape
hatch to configure.
